# 算法拾级

面向会写简单 Java、尚未系统学习算法与数据结构的个人学习网站。以用户提供的《Hello 算法》Java 版 PDF 为教材，通过短课、可操作的算法演示、分层练习和复习记录，逐步建立独立解题能力。

## 在线使用与自动发布

本项目通过 GitHub Actions 构建并发布到 GitHub Pages，目标地址为 **[算法拾级](https://ryancheng08.github.io/algorithm-steps/)**。构建与部署状态可在 [GitHub Actions](https://github.com/RyanCheng08/algorithm-steps/actions/workflows/pages.yml) 查看。

向本仓库的 `main` 推送会自动运行测试、在 JDK 17 上验证 Java 示例、构建静态文件并发布。Pull Request 只验证、不发布。具体流程见 [部署说明](docs/自动构建与发布.md)。

在线版保留全部课程、实验、短题、笔记和 Java 下载入口；教材通过官方在线入口查阅，不上传本机 PDF。在线版与本地版的进度独立保存，如需迁移，在原地址导出备份，再到新地址导入。

## 启动网站

需要 **Node.js 18 或以上版本**，并能在终端使用 `node`。项目没有第三方 npm 依赖，**不需要运行 `npm install`**。

在 Windows 中双击项目根目录的 [启动学习网站.cmd](启动学习网站.cmd)，保留打开的终端窗口，然后在浏览器访问固定地址：

**[http://127.0.0.1:4173](http://127.0.0.1:4173)**

也可以在 PowerShell 中启动：

```powershell
Set-Location -LiteralPath 'E:\学习\AI change my life\06计算机基础学习\算法学习'
npm start
```

同样在浏览器打开上面的地址。脚本启动本地服务，不会自动打开浏览器。学习期间保持终端运行，结束后在终端按 `Ctrl+C` 停止；下一次重新启动即可。不要直接双击 `index.html`，页面使用 JavaScript 模块和本地服务端点。

如果提示 `node` 不是可识别的命令，先准备 Node.js；如果提示端口被占用，检查是否已经有一个学习网站在运行，优先复用原服务。默认服务只绑定本机 `127.0.0.1`。

## 现在可以学什么

首版包括 **12 节课程、36 道随堂短练习、12 个独立编程挑战、48 道 LeetCode 候选题**。其中 8 道 LeetCode 题与当前课程关联，另外 40 道属于后续路线，卡片注明尚未开放的前置课程。链表、树、堆、图、回溯、动态规划与贪心目前展示为后续规划。

12 节课程依次覆盖：算法与输入输出、数组下标、遍历求和、最大值、顺序查找、复杂度直觉、二分查找、查找边界、选择排序、冒泡排序、插入排序、双指针与移动零。

推荐每节课按以下顺序学习：

1. 在“讲解”理解目标、场景和容易出错的地方，必要时按来源页码回看教材。
2. 在“实验与代码”换一组数据，单步前进、后退，观察数组、变量和 Java 代码的对应关系。
3. 在“随堂练习”先独立作答，需要时使用提示；答案、解析、错因都会随记录保存。
4. 在“编程挑战”独立写出 Java 方法，在本机运行边界用例，再按前置知识选择 LeetCode 题。
5. 在“复习与笔记”回顾到期课程和错题，用自己的话记录理解。

网页中的演示由确定性的 JavaScript 算法生成。Java 挑战在本地 JDK 中运行，本站不提供浏览器内的 Java 编译器。LeetCode 卡片打开官方题页，由官网负责提交和评测；本站的完成状态是你的手动记录。

## 进度、独立通过与复习

- **已阅读**：主动点击“标记阅读完成”，与随堂题结果分别记录。
- **练习通过**：当前一轮的全部随堂题已答对，允许使用帮助或订正。
- **独立通过**：当前一轮全部答对，且没有使用提示、揭晓答案或答错后订正。重新开始一轮会清除本轮答案、帮助和错误记录，保留累计尝试次数。
- **待复习**：答错时立即加入；首次全部答对后安排 1 天后复习。到期复习时，每道题都需要在本次到期时间之后重新作答并全对，才推进到 3、7、14 天。未到期重复提交不会提前推进；答错再订正按原阶段重新安排。

进度与笔记保存在**同一浏览器、同一浏览器配置、同一网站地址**的本地存储中。建议始终使用 `http://127.0.0.1:4173`，不要交替使用 `localhost` 或不同端口；这些地址的浏览器记录相互独立。更换浏览器、换电脑、使用无痕窗口或清理网站数据后，原记录不会自动跟随。

点击页面上方“导出记录”保存 JSON 备份。恢复时点击“导入备份”，选择文件，查看记录概况并确认替换；取消或无效文件不会覆盖现有记录。也可以在“复习与笔记”页面进行这些操作。**换设备或清理浏览器前先导出备份**。

若浏览器拒绝保存，页面会提示当前记录仅在本次页面中暂存，请在离开前导出。已有记录损坏时，网站提供“导出原始记录”，避免直接覆盖原始数据。

## 运行 Java 练习

课程代码采用 Java 8 可用的基础语法，兼容 Java 8 / Java 17。本地验收使用 **JDK 8**；GitHub Actions 已在 **Temurin JDK 17** 上实际编译并运行自检，后续每次发布都会重复验证。

课程页可以下载 [AlgorithmLab.java](java/AlgorithmLab.java) 与 [AlgorithmLabTest.java](java/AlgorithmLabTest.java)。在两个文件所在目录执行：

```powershell
javac -encoding UTF-8 AlgorithmLab.java AlgorithmLabTest.java
java AlgorithmLabTest
```

参考源码包含全部 12 个方法。建议先单独写出自己的实现，再对照相应输入与预期结果检查；课程页的“我已在本地完成”是自我记录，不代表网站运行过你的代码。

开发维护时，参考源码由课程中的同一份方法生成：

```powershell
npm run java:generate
npm test
```

修改自己的练习前请另存副本，`java:generate` 会重新生成 `java/AlgorithmLab.java`。实际交付验证项目与结果见 [开发验收记录](docs/开发计划与验收记录.md)。

## 教材

本地来源：`E:/学习/e-book/hello算法-java版本 (靳宇栋 (Krahets)) (Z-Library).pdf`，376 页，版本页标注 2023-09-10 / Release 1.0.0b5。

本地服务通过固定的 `/textbook.pdf` 只读端点打开这一本 PDF；课程中的“打开原书”链接带有 PDF 页码。文件不在默认位置时，“回到教材”仍显示章节与页码，课程本身可以继续学习。可以在启动前通过环境变量 `ALGORITHM_PDF` 指定自己的同版本 PDF 路径；如果换成不同版本，请核对页码是否仍一致。

本站课程、实验、练习与本地记录可以离线使用；访问 Hello 算法官网或 LeetCode 需要网络。

# 课程与练习设计

本文定义学习路线、教学目标、练习来源和通过标准，是首版课程内容的开发依据。文中“首版”表示计划交付范围；是否已实现、是否已验证，以项目实现和验收记录为准。

## 1. 学习者与课程原则

学习者已经能够阅读简单 Java，使用变量、条件、循环、方法和数组，但没有系统学习算法与数据结构。课程使用简单、可读的 Java 示例；遇到对象引用、递归等新概念时，再补充必要知识。

- 一课解决一个主要问题，先给具体例子，再抽象为规则和代码。
- 先预测，再观察执行；先解释原因，再补全代码，最后独立实现。
- 教材是知识主线。为降低学习门槛，推荐路线调整了部分章节的顺序。
- 阅读、练习、提示使用和复习分别记录；浏览完毕不等于掌握。
- 同一问题可有多个正确实现，不能通过与参考代码的文字一致程度判分。
- 时间复杂度围绕输入规模、操作次数和增长趋势讲解，不用某一次网页动画的运行时间代替复杂度。

## 3. 首版范围与顺序

首版包含 12 节完整基础课。默认推荐顺序如下，已熟悉的课程可以跳转阅读，但练习与掌握记录保持独立。

`算法与输入输出 → 数组与下标 → 遍历与求和 → 找最大值 → 顺序查找 → 操作次数与复杂度 → 二分查找 → 查找边界与插入位置 → 选择排序 → 冒泡排序 → 插入排序 → 双指针与移动零`

| 序号 | 稳定 ID | 课程 | 核心能力 |
| --- | --- | --- | --- |
| 01 | `algorithm` | 算法与输入输出 | 把需求写成明确的输入、处理步骤和输出 |
| 02 | `array` | 数组与下标 | 区分元素、下标、长度和合法访问范围 |
| 03 | `sum` | 遍历与求和 | 用循环和累加器处理全部元素 |
| 04 | `max` | 找最大值 | 维护迄今为止的最佳答案 |
| 05 | `linear` | 顺序查找 | 返回目标位置，并正确处理未找到 |
| 06 | `complexity` | 操作次数与复杂度 | 用输入规模解释算法工作量的增长 |
| 07 | `binary` | 二分查找 | 利用有序性排除不可能的范围 |
| 08 | `boundary` | 查找边界与插入位置 | 处理重复元素和目标不存在的情况 |
| 09 | `selection` | 选择排序 | 从未排序区选择最小元素 |
| 10 | `bubble` | 冒泡排序 | 通过相邻比较逐轮确定元素位置 |
| 11 | `insertion` | 插入排序 | 把新元素插入已经有序的前缀 |
| 12 | `two-pointers` | 双指针与移动零 | 用读、写位置完成稳定的原地整理 |

所有编程题都明确输入约束，包括是否允许空数组、是否有序、是否有重复元素，以及结果是否需要修改原数组。首版默认数组引用非 `null`；需要讨论 `null` 的题必须另行声明。求和题约定累加过程和结果均在 `int` 范围内，后续再讨论溢出与 `long`。方法统一为 `public static`，每课的方法名唯一。

## 4. 各课设计

### 01 算法与输入输出 · `algorithm`

- **目标：** 能将简单需求拆成输入、确定步骤和输出，知道同一任务可以有不同做法。
- **前置：** 会调用 Java 方法，认识参数和返回值。
- **内容：** 算法处理什么问题；方法签名与输入输出约定；用购物清单计算总价说明确定性与边界；用有限步骤描述解决过程。
- **教材入口：** 第 1 章，书内第 9 页 / PDF 第 15 页。购物清单练习和输入输出检查是原创辅助。
- **短练习：** 识别一项需求的输出；预测中途总价；填写空清单的结果。
- **独立编程：** 实现 `int totalPrice(int[] prices)`，以整数分表示价格，总和在 `int` 范围内；先写样例和步骤，再尝试实现。后续求和课会展开解释循环。
- **通过标准：** 能说明参数和返回值含义；步骤可执行且能结束；正确处理空清单、单件和多件商品。

### 02 数组与下标 · `array`

- **目标：** 区分数组的长度、下标和元素值，能读写指定位置。
- **前置：** `algorithm`；Java 数组声明与赋值可随课回顾。
- **内容：** 下标从 0 开始；合法范围 `[0, length - 1]`；访问、修改与遍历的区别；空数组没有可访问的元素；数组长度固定的直觉。
- **教材入口：** 数组，书内第 64 页 / PDF 第 70 页。
- **短练习：** 预测指定下标的元素；识别越界访问；填写末元素的下标。
- **独立编程：** 实现 `int valueAt(int[] nums, int index)`，合法位置返回对应元素，非法位置抛出 `IndexOutOfBoundsException`。
- **通过标准：** 正确识别首尾下标；能区分元素值与位置；非法位置明确报错；知道空数组不存在合法下标。

### 03 遍历与求和 · `sum`

- **目标：** 理解循环变量和累加器各自的作用，能处理所有元素且不重不漏。
- **前置：** `array`、`for` 循环。
- **内容：** 从 0 初始化累加器；循环前后状态；空数组求和为 0；整数范围由题目保证。前缀和只作为可选拓展的后续阅读提示，不纳入首版必会内容。
- **教材入口：** 数组，书内第 64 页 / PDF 第 70 页；迭代相关内容，书内第 18 页 / PDF 第 24 页。求和情境和练习为原创辅助。
- **短练习：** 预测中途累加器；识别正确遍历范围；补全 Java 循环条件中的比较运算符。
- **独立编程：** 实现 `int sum(int[] nums)`，保证累加过程与结果不溢出。
- **通过标准：** 通过空数组、单元素和正负数混合测试；能解释每个元素恰好处理一次。

### 04 找最大值 · `max`

- **目标：** 维护已经遍历部分中的最大值，理解初始化必须满足输入约束。
- **前置：** `sum`、条件判断。
- **内容：** 最大值初始化为第一个元素；从第二个元素开始比较；负数与重复最大值；“当前答案”只针对已处理元素。空数组没有最大元素，方法对此明确抛出异常。
- **教材入口：** 数组，书内第 64 页 / PDF 第 70 页。找最大值的拆解、演示与题目为原创辅助。
- **短练习：** 预测下一步最大值；选择合理初值；找出全负数时初始化为 0 的错误。
- **独立编程：** 实现 `int max(int[] nums)`；非空数组返回最大值，空数组抛出 `IllegalArgumentException` 并说明无法求值。
- **通过标准：** 通过全负数、单元素、最大值在首尾和最大值重复的测试；空数组明确报错，不能虚构最大值 0。

### 05 顺序查找 · `linear`

- **目标：** 按顺序检查元素，返回第一个目标位置，未找到时返回 `-1`。
- **前置：** `array`、`max`；理解提前返回。
- **内容：** 比较元素值与目标；返回位置与返回值的区别；重复元素的第一个位置；提前返回；遍历结束后才判定不存在。
- **教材入口：** 数组，书内第 64 页 / PDF 第 70 页。顺序查找课程编排和练习为原创辅助；不把本课包装成教材同名原题。
- **短练习：** 跟踪第一次命中；计算查找检查次数；修复把“未找到”放在循环内部的错误。
- **独立编程：** 实现 `int linearSearch(int[] nums, int target)`。
- **通过标准：** 通过空数组、首尾命中、重复值和不存在测试；返回的是第一个命中的下标。

### 06 操作次数与复杂度 · `complexity`

- **目标：** 把输入规模与操作次数联系起来，建立常数、线性、平方和对数增长的直觉。
- **前置：** `sum`、`linear`。
- **内容：** 先约定统计的基本操作；比较常数次操作、一次遍历、两层完整遍历；区分最好与最坏情况；用不断减半解释对数增长；认识 `O(1)`、`O(n)`、`O(n²)`、`O(log n)`。首版不要求推导递归复杂度。
- **教材入口：** 时间复杂度相关内容，书内第 25 页 / PDF 第 31 页。互动计数实验为原创辅助。
- **短练习：** 匹配计数表与增长趋势；预测输入翻倍后的操作次数；识别“一个循环必定是 O(n)”的错误概括。
- **独立编程：** 实现 `int countVisits(int[] nums)`，完整遍历并统计访问元素次数，空数组返回 0。
- **通过标准：** 能解释计数口径和输入翻倍的影响；能够说明完整遍历是 `O(n)`，顺序查找最好 `O(1)`、最坏 `O(n)`，并区分实际次数与增长数量级。

### 07 二分查找 · `binary`

- **目标：** 理解有序性为什么允许排除一半候选，并独立实现基本二分查找。
- **前置：** `linear`、`complexity`。
- **内容：** 升序输入前提；闭区间 `[left, right]`；安全中点 `left + (right - left) / 2`；命中、向左、向右三种情况；范围为空时终止。主练习使用无重复数组，避免混淆任意命中和边界查找。
- **教材入口：** 二分查找，书内第 205 页 / PDF 第 211 页。
- **短练习：** 选择正确的边界更新；判断二分查找的输入前提；补全 `left = ____`，排除已经检查过的中点。
- **独立编程：** 实现 `int binarySearch(int[] nums, int target)`，升序且无重复，未找到返回 `-1`。
- **通过标准：** 通过空数组、单元素、首尾命中、目标小于最小值或大于最大值、目标位于两个值之间等测试；能解释每轮范围严格缩小。

### 08 查找边界与插入位置 · `boundary`

- **目标：** 从“找到任意一个”过渡到“找到第一个满足条件的位置”。
- **前置：** `binary`；理解返回值可以等于数组长度。
- **内容：** 下界是第一个 `>= target` 的位置；不存在时为 `n`；半开区间 `[left, right)` 与基本查找的闭区间对照；重复元素的最左位置；插入位置的含义。上界和最后一个相等值作为讲解中的延伸，不混入首个必做实现。
- **教材入口：** 二分查找插入点，书内第 209 页 / PDF 第 215 页；边界，书内第 213 页 / PDF 第 219 页。
- **短练习：** 识别重复值的最左下界；解释返回数组长度的含义；补全 lowerBound 的返回边界变量，接受循环结束后等价的 `left` 或 `right`。
- **独立编程：** 实现 `int lowerBound(int[] nums, int target)`，升序、允许重复，返回 `[0, nums.length]` 中的位置。
- **通过标准：** 通过空数组、全部相等、多段重复、插入首尾和中间测试；能说明为什么返回 `n` 合法且不能直接访问 `nums[n]`。

### 09 选择排序 · `selection`

- **目标：** 通过“找到最小值并交换”建立排序的分阶段思路。
- **前置：** `max`、`array`、`complexity`。
- **内容：** 已排序前缀与未排序后缀；记录最小元素的下标；一轮扫描结束再交换；原地修改；比较次数与 `O(n²)`。不要求初学者证明稳定性。
- **教材入口：** 选择排序，书内第 224 页 / PDF 第 230 页。
- **短练习：** 预测一轮结束后的数组；选出最小值下标；修复在扫描中错误更新下标的问题。
- **独立编程：** 实现 `void selectionSort(int[] nums)`。
- **通过标准：** 通过空数组、单元素、已有序、逆序、负数与重复值测试；能描述每轮固定了哪个位置。

### 10 冒泡排序 · `bubble`

- **目标：** 理解相邻比较如何把较大的值逐步推向右侧。
- **前置：** `selection`。
- **内容：** 相邻比较与交换；每轮减少待处理末端；边界 `j + 1`；用是否交换实现提前结束；无提前结束和有提前结束版本的区别。
- **教材入口：** 冒泡排序，书内第 227 页 / PDF 第 233 页。
- **短练习：** 执行一次相邻交换；预测一轮后确定的位置；修复比较范围越界或 `swapped` 未逐轮重置的问题。
- **独立编程：** 实现带提前结束的 `void bubbleSort(int[] nums)`。
- **通过标准：** 通过基础排序边界测试；有序输入一轮后能结束；能说明优化后的最好情况是 `O(n)`、最坏仍为 `O(n²)`。

### 11 插入排序 · `insertion`

- **目标：** 理解“保存当前值，移动较大元素，再放回空位”的过程。
- **前置：** `selection`、`bubble`；会使用 `while`。
- **内容：** 有序前缀；临时保存待插入值；从右向左比较与移动；先检查下标再访问；写回 `j + 1`；近乎有序输入的直觉。
- **教材入口：** 插入排序，书内第 230 页 / PDF 第 236 页。
- **短练习：** 判断需要右移的元素；解释保存 `base` 的原因；补全 `nums[____] = base` 中的插入位置表达式。
- **独立编程：** 实现 `void insertionSort(int[] nums)`。
- **通过标准：** 通过基础排序边界测试；能展示一次向首部插入的完整状态变化；用相同输入比较三种基础排序的主要操作。

### 12 双指针与移动零 · `two-pointers`

- **目标：** 用两个位置承担不同职责，在原数组中完成整理并保持非零元素相对顺序。
- **前置：** `array`、`linear`；熟悉原地修改。
- **内容：** `read` 检查输入、`write` 记录下一个非零值位置；先按原顺序写入非零值，再填充零；有意义的已处理区间；`O(n)` 时间和 `O(1)` 额外空间；读写指针无需同步移动。
- **教材入口：** 数组基础，书内第 64 页 / PDF 第 70 页。双指针课程、动画和小练习为原创辅助，不声明是该页的教材原题；对应 LeetCode 题单条目另标来源。
- **短练习：** 预测读写位置；执行一次非零值写入；修复仅跳过零却未清理尾部的问题。
- **独立编程：** 实现 `void moveZeroes(int[] nums)`，保持非零值相对顺序。
- **通过标准：** 通过空数组、全零、无零、首尾零、连续零与重复非零值测试；能解释为什么结果长度不变且原顺序保留。

## 5. 首版配套题数量与来源边界

每课配置为 2 道选择题、1 道填空题和 1 道独立 Java 方法题，共 36 道短练习、12 道方法题。选择题覆盖状态预测、概念判断和错误辨别；填空题包含 4 道关键代码补全（求和循环条件、二分边界更新、lowerBound 返回位置、插入排序写回位置），其余练习为数值或复杂度判断。代码填空说明填写范围，并接纳列明的等价表达式；独立 Java 任务仍按实际结果验证，不能用参考代码的文字一致程度判定。

这是课程内容的编写数量，不意味着每道 Java 方法题都在网页里自动执行。界面必须说明验证方式：

- 浏览器能够自动判定的选择、预测和填空题，按预设答案与解释反馈。
- Java 示例和参考答案应由开发者实际编译、运行代表性与边界用例后发布。
- 用户自己编写的 Java，如果没有提交给真实 Java 执行环境，只能记录用户自评或用户提供的运行结果；不得显示“自动测试通过”。
- “展开答案”单独记录；同一题看过完整答案后立即答对，记为辅助完成。后续重新独立完成才能建立独立练习记录。

练习来源分成四类并显式展示：

| 来源类型 | 应展示的信息 | 不应混淆的边界 |
| --- | --- | --- |
| 教材例题 | 章节、书内页码、PDF 页码 | 不把新编题标成教材原题 |
| 原创配套 | 对应知识点、原创辅助标识 | 可以借助教材概念，但不声称来自书中 |
| 教材变式 | 原知识点与新增条件 | 说明改变了什么约束或目标 |
| LeetCode 精选 | 题号、题名、原题链接、先修课程 | 以原站题面和判题结果为准，不虚构提交状态 |

LeetCode 用于专题迁移练习，独立于上述 48 道配套题。完整基础路线计划精选约 40～60 道，而非首版就要求学习者完成全部题目。取题范围、筛选和逐题验证记录由专门题单文档管理；同一道题即使属于多个官方题单也只保留一个条目。第一版只突出与已实现课程相符的候选，未开课专题标为后续计划。

## 6. 提示、通过标准与复习

### 提示层级

1. **方向提示：** 告诉学习者应该观察什么，例如先确认候选区间是否有序。
2. **步骤提示：** 给出关键状态或更新原则，但保留实际代码。
3. **参考解法：** 展示完整思路与 Java 实现，明确已阅读答案。

使用提示不是失败，应当保留真实记录。练习反馈说明错在哪里、为什么，以及可以返回哪一节课补习。

### 能力状态

| 记录维度 | 触发方式 | 可以得出的结论 |
| --- | --- | --- |
| 已阅读 | 用户显式标记，或完成课程阅读流程 | 接触过本课，不代表会做题 |
| 已练习 | 至少作答一道题 | 开始应用知识 |
| 辅助完成 | 使用步骤提示或参考答案后完成 | 能在帮助下完成 |
| 独立短题完成 | 本轮未使用任何提示或答案且短题全部答对 | 具备本课基础判断能力 |
| Java 自评完成 | 用户在本地运行后显式确认 | 仅代表用户声明，不代表网站自动验证 |
| Java 自动验证通过 | 真实执行环境运行规定用例并返回成功 | 该实现通过已覆盖用例，不证明所有输入都正确 |
| 待复习 / 已复习 | 按最近一次独立尝试与复习结果记录 | 描述记忆与应用的保持情况 |

首版课程通过的目标是：短练习完成并理解错因，能解释主要步骤，并完成独立方法题。没有真实执行环境时，进度显示“短题完成 + Java 自评”，不要把它汇总成“系统认证掌握”。编程练习的独立性与验证方式必须保留。

复习采用轻量默认建议：首次练习全部答对安排 1 天后复习；到期后重新通过再依次推进 3、7、14 天间隔。未到期反复作答不推进阶段；失败则优先返回错误概念。此节描述的是站内学习建议，不创建系统通知、消息发送或后台定时任务。用户可以手动选择复习或暂缓，间隔属于可调整的学习安排，不是掌握能力的科学保证。

复习入口优先呈现：最近答错的知识点、使用过完整答案的题、到期的独立回忆题。重复打开页面不应新增练习记录；重复提交可记录尝试，但不能刷高掌握率。

## 8. 内容验收清单

- 12 个稳定 ID 唯一；每课具有目标、前置、讲解、互动、练习、来源和通过标准。
- 教材跳转展示两个页码，链接使用 PDF 阅读器页号，使用前核验对应页面。
- 原创辅助、教材例题、教材变式和外部题来源可辨认。
- 每道题包含清楚的约束、答案或参考实现、答案解释和边界说明。
- Java 参考实现实际编译运行；教材风格与参考实现一致不等于未经运行就通过验证。
- 空数组、单元素、重复值、负数、未找到和首尾边界按各题约束覆盖。
- 动画状态、代码高亮和文字说明对应同一步；用户能暂停、重置和逐步执行。
- 学习进度能够分别表达阅读、辅助完成、独立完成、自评和真实自动验证。
- 后续专题有清楚的计划状态；已有练习不依赖尚未教授的知识。

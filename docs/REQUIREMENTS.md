# 学习网站需求

## 已确认的使用者与目标

使用者能阅读简单 Java，能写循环和数组操作，但数据结构与算法接近零基础。目标是理解原理、跟踪变量、独立实现基础算法，并逐步完成有针对性的 LeetCode 练习。界面与讲解使用中文，代码使用 Java。

学习顺序遵循先修知识，保留原书章节索引。复杂度先从操作计数建立直觉；递归、树、图、动态规划等放在基础课程之后。无需先重复完整 Java 语法课程，遇到引用、泛型等概念时补充够用的说明。

## 首版用户流程

1. 首页显示继续学习入口、阅读与练习的独立统计、待复习内容及推荐下一课。
2. 路线页展示 12 节已实现课程和后续规划。学习者可以自由浏览，有缺失前置时给予提示，不强制锁课。
3. 每课有目标、生活场景、分步讲解、操作实验、Java 代码、常见错误、3 道随堂练习和一个独立编程任务。
4. 演示允许换数据、单步前进、后退和重置，显示变量、数组状态、操作计数、过程解释。计数口径明确，不将浏览器耗时作为复杂度证明。
5. 练习包含选择/预测和短答案填空，先提交再反馈，提供逐级提示，保存最近回答与错误原因。
6. 练习页可筛选当前可做的 LeetCode 题，打开官网并手动记录未开始、尝试中、已完成。手动标记不得声称官方已通过。
7. 复习页汇集错题与到期课程。通过复习才推进复习间隔，打开页面不会自动计为掌握。
8. 学习笔记按课保存；全部进度和笔记可导出 JSON，也可验证格式后导入。导入覆盖现有记录前需在界面确认。

## 第一版内容

12 节：算法与输入输出、数组下标、遍历求和、最大值、顺序查找、复杂度直觉、二分查找、查找边界、选择排序、冒泡排序、插入排序、双指针与移动零。

每课约 15～25 分钟为建议节奏，非完成时长保证。首版包含 36 道随堂题、12 个独立编程任务，后者提供思路提示、参考方法和测试用例，需要本地 Java 执行验证。完整候选题单 48 道，其中 8 道关联当前课程、40 道关联后续规划；后续章节相关题明确标注先修未覆盖。

## 进度定义

- 已阅读：学习者主动标记阅读完成。
- 练习通过：本课随堂题当前全部答对；保留本轮提示、揭晓答案和错误订正记录。
- 独立通过：当前轮全部随堂题答对，且没有使用提示、揭晓答案或错误订正。答错时显示解析以帮助学习，随后订正只计为练习通过；重新开始一轮后可以再次尝试独立通过。
- 待复习：答错时立即加入；首次全对安排 1 天后复习。到期后必须每题都在本次到期时间之后重新作答并全对，才将间隔推进到 3、7、14 天；不能沿用上一轮答案，只重答一题就推进。未到期重复提交不推进，答错后订正按原间隔级别重新安排。
- 编程完成：学习者自报本地完成，不自动等同于在线评测通过。
- LeetCode 完成：学习者手动记录，界面明确展示此性质。

不根据停留时间、打开课程或播放演示直接宣布掌握知识。学习记录只表示本站的练习行为。

“重新开始本轮”清除该课本轮答案、提示、揭晓与错误次数，保留累计尝试、阅读标记和已有复习安排。进入课程或切换标签页不自动重置练习。

## 来源与使用边界

课程来源保留书内页码与 PDF 页码，已核对部分两者相差 6 页。新编内容标记为原创辅助或教材变式。LeetCode 只提供元数据、原创学习建议、官方题目链接，不导入账户、不抓取提交记录、不复制平台题解。

第一版按会话中已确认的本地方案开发，无注册、账号同步、AI 服务、付费 API 或在线任意 Java 执行。将来若需跨设备同步、部署或在线判题，另行确定运行方式；本地学习无需这些数据。

## 体验要求

浅色阅读界面，正文清晰，桌面优先并适配窄屏。键盘可操作表单与步骤按钮，状态不仅依赖颜色；支持减少动画。首次使用没有虚构进度、打卡记录或评价。存储失败时提示并允许导出，不能静默丢失学习数据。

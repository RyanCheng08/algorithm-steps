### 启动与使用

在项目目录双击 `启动学习网站.cmd`，或运行 `npm start`，再打开 **http://127.0.0.1:4173**。需要 Node.js 18 或以上，无需执行 `npm install`。服务仅监听本机回环地址。关闭启动窗口后服务停止，再次学习时重新启动即可。

先点击“开始第一课”，按讲解 → 实验 → 随堂练习 → 本地 Java 挑战学习。教材按钮通过固定的只读本地接口打开原 PDF，不复制教材到项目。完整说明见 [README](../README.md)。

### 当前边界

网页内是确定性的算法推演与短题判定，Java 编程在本地 JDK 运行。参考源码的自检通过不等于学习者自己的实现已通过；页面中的本地挑战和 LeetCode 完成状态属于用户自我记录。

没有账号系统、云同步、在线 Java 判题或 LeetCode 登录/提交同步。本站讲解、实验、短题与笔记可在本地使用；打开 LeetCode 或官方教材网站需要网络。浏览器清理站点数据会影响学习记录，支持导出 JSON 备份并在同版本页面导入。
